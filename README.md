# Investment Portfolio Intelligence

A project for ingesting, transforming, and analyzing investment portfolio data.

## Structure

- `src/ingestion/`: Data ingestion pipelines
- `src/transformation/`: Data cleaning and transformation logic
- `src/utils/`: Shared utilities
- `infrastructure/`: Infrastructure and deployment configuration
- `sql/`: SQL queries and database scripts
- `tests/`: Automated tests
- `docs/`: Project documentation
